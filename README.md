# World-cities-analysis-project
## Description
The project concetrates on the analysis of the data about cities, such as population, country, location etc. and graphic depiction of it.

## Installation
The project is available on the Github repository: https://github.com/arsenysinitsky/Project-2-about-World-Cities Install the repository as an archive, unpack it and launch the .ipynb file. Please make sure that .ipynb file is located in the same folder that the file "worldcities.csv" is.

## Used data
The datset used in the project is available by the link: https://www.kaggle.com/datasets/juanmah/world-cities
